# 紅葉ヒルクライム

嵐山-高雄パークウェイをモチーフにした秋の山道を駆け上がるヒルクライム・ゲーム（1ファイルのHTML）。GitHub Pages で公開中。

- 遊ぶ: https://kokadaroadster-ui.github.io/momiji-hillclimb/
- コース: 嵐山・清滝口ゲート → 花街道 → 小倉山のアップダウン → 保津峡展望台・保津川橋 → 愛宕前のつづら折り → 愛宕橋 → 菖蒲谷池・池の橋・菖蒲ヶ丘展望台 → 紅葉のトンネル → 高雄大駐車場（ロードスターミーティング会場）
- 障害物: 落石・パイロン・バリケード・落ち葉だまり・水たまり（当たると減速）
- 天気と時間帯: 夕方から霧・雨を経て夜へ。雨のときはワイパーが動く
