# 紅葉ヒルクライム

嵐山-高雄パークウェイをモチーフにした秋の山道を駆け上がるヒルクライム・ゲーム（1ファイルのHTML）。GitHub Pages で公開中。

- 遊ぶ: https://kokadaroadster-ui.github.io/momiji-hillclimb/
- コース: 嵐山・清滝口ゲート → 花街道 → 小倉山のアップダウン → 保津峡展望台・保津川橋 → 愛宕前のつづら折り → 愛宕橋 → 菖蒲谷池・池の橋・菖蒲ヶ丘展望台 → 紅葉のトンネル → 高雄大駐車場（ロードスターミーティング会場）
- 障害物: 落石・パイロン・バリケード・落ち葉だまり・水たまり（当たると減速）
- Wボタン: 走行中に画面左下のWボタンを押すと、タイヤが鳴ってスピンし、路肩へコースアウト。少し間をおいて立て直し、走行に戻る（キーボードのWはアクセルのまま）
- Wボタン3回連続: 1.6秒以内に3回押すと、3回目でスピンをキャンセルしてバック・トゥ・ザ・フューチャー風のタイムトラベル。チャージ（88 MPH・1.21 GW表示、青白い電撃）→閃光→1985年に切り替わって炎のタイヤ跡を残し爆走→元の時間へ帰還（操作は戻る）。コースも少し先へワープし、タイマーはその間止まる
- Wボタン10回連打: 3.8秒以内に10回押すと、雷と閃光とともに博士（doc.png）が登場し、光るポールの周りでポールダンスを踊る（ディスコ照明・紙吹雪・ファンキーなBGMつき、約5.8秒）。走行は止まらない
- Wボタン長押し: 0.6秒押し続けると、アニメ化したキャラ（giant_char.png）がマリオのキノコのように巨大化してフロントガラス前に出現する（段階的に膨らむ拡大・集中線・スターバースト・キラキラ・軽い画面揺れ・8bitのパワーアップ音、約3秒）。走行は止まらない。短い1回押しのスピンや3回・10回の連打はそのまま
- 天気と時間帯: 夕方から霧・雨を経て夜へ。雨のときはワイパーが動く

### 追加の敵キャラ・アイテム（2026-11-20）

- 紅葉タカ（ステージ1）: 上空を旋回し、近づくと急降下してくる。踏みつけ可能。急降下中は「!」が出る
- 紅葉シカ（ステージ1）: 左右にステップしながら道をふさぐ。枝角があるので踏めない（ジャンプでよける）。角に紅葉がついている
- 鬼火（ステージ2）: 青白い炎がゆらゆら浮遊。踏めず、触るとダメージ。高度が低いときはジャンプで越える

### 2段階パワーアップ（BIG → MEGA）

- 1回目のパワーアップ（Wゲージ満タン、またはPOWERオーブ）で「BIG」（1.55倍・約7.6秒）
- BIGの状態でもう一度パワーアップすると「MEGA」（2.15倍・約10.6秒）。専用の紫〜紅のオーラ・地面の二重リング・周回する光・MEGA!!表示・専用8bitパワーアップ音つき
- MEGAは着地で画面が大きく揺れ、足元の敵（半径170）をふき飛ばす。当たり判定も2段階で拡大。ゲージは巨大化中もたまる（2回目のパワーアップを狙える）

### ボスの可変攻撃（本気モード）

- 残りHP 65%以下で「本気」、35%以下で「本気MAX」にフェーズ変化（HPバーが赤く脈打ち、⚠ SPEED UP / SPEED MAX バナー表示）
- フェーズごとに移動速度・攻撃間隔・弾速が上がる（速度×1.42 / ×1.84、BGMのテンポも上昇）
- 本気からはドクが3方向の扇状弾、非案内人が3方向のダークボール／両方向ショックウェーブを使う。本気MAXではドクの突進（ジャンプでよける）と連射、超加速バースト（残像スピード線）、非案内人のフェイントジャンプ→両方向衝撃波が加わる

### 🎵 キャラ別BGM と GSミアタのボイス（2026-11-23）

**キャラ別の 走行BGM**（ステージ1の 通常走行曲が 主人公で 切り替わる）

**GSミアタの ボイス（声真似・Web Speech API）**

- `window.speechSynthesis` で 「**ハイオク満タン！**」「**In Japan we say...!**」「**オーライ、オーライ！**」「**ハイオク満タン、ブースト！**」を 喋る
- 発話文（音声 v3・2026-11-23）: 画面表示は 漢字・英語のまま、`speak()` へは カタカナ読みを 渡す。漢字「満」は iOSの 日本語音声が 名前読みの「みつる」と 読むため、**「ハイオク マンタン！」**（ブーストは「ハイオク、マンタン、ブースト！」）／**「In Japan we say...!」→「イン ジャパン、ウィー セイ！」**。最後の砦として `満→マン` も 置換し、漢字が 残らない
- 声色: **「ハイオク満タン！」＝日本人男性**（`ja-JP`・Otoya／Hattori 等を 優先、pitch **0.82**、rate 1.05。男性名の声が 無ければ 端末既定の日本語音声＋pitch 0.82 の 低め）／**「In Japan we say...!」＝日本の 若い女の子**（`ja-JP`・Kyoko／O-Ren／Haruka 等を 優先、pitch **1.38**、rate **1.08**。英語ネイティブの `en-US` は 使わない）／その他（オーライ・給油所の ワッカー等）＝キャラ声（イッセイ 0.90／ミニー 1.30、rate 1.12）
- 鳴る場所: **Wの 相方コンビ必殺技**（2こと連続）／**給油所の 通過**／**RIDE ハイオクブースト**／**▼の オーライ誘導**
- ミュート中は 喋らず、ミュートした瞬間に 発話も 止める。連続発話は 2.2秒（セリフ連続は 2.6秒）の クールダウンと `cancel()` で かぶらない。iOS Safari 対策として START・最初のタップ／キー入力で アンロック
- 検証フック: `__dash.voiceInfo()`（`readJa` / `readBoost` / `readEn` / `gasVoice` / `girlVoice` / `gasPitch` / `girlPitch`）/ `voiceTest(text)` / `voiceLines()` / `voiceReading(text)` / `voiceRoleOf(text)` / `voiceUnlock()` / `voiceCancel()` / `voiceResetCooldown()`

### 🚀攻撃の違い：ワッカー＝ミサイル／波動砲、イッセイ・ミニー＝ガソリン噴射（2026-11-23）

- **ワッカー（default）**: これまでどおり。短押し＝ミサイル（水中は魚雷）、長押しMAX＝波動砲（極太の青白い貫通ビーム）
- **イッセイ・ミニー（issei / minnie）**: 🚀が **ガソリン噴射** に変化する
  - **短押し**: ノズルから 先端へ扇形に広がる **黄金〜虹色の燃料ジェット**（白い芯・緑と水色の屈折光の縁・虹色の飛沫・ノズル光・後方の燃料ミスト）。当たると ガソリン飛沫が散る
  - **長押しMAX**: **超高圧ガソリンジェット**。極太の黄金→虹色の帯（乱流の白い筋・飛び散る飛沫・先端の閃光・衝撃波リング）で、従来の波動砲と同じ **貫通・6ダメージ**（0.35秒以上で離すと小噴射 2ダメージ）
  - **性能は ワッカーの ミサイル／波動砲と 同等以上**: 弾速・連射間隔（0.22秒）・威力（1／2／6）は同じで、ガソリン噴射は 射程が少し長く（life 1.9→2.1秒）、飛沫ぶん 当たり判定を広め（障害物 ±11、敵弾 +16）にとっている
  - 画面の演出も専用: チャージ中の粒子と光球が 黄金／緑、MAX表示は「MAX！ ガソリン満タン」、発射ポップは「GASOLINE JET!!」、ボス直撃メッセージは「⛽ガソリン噴射 直撃！」。🚀ボタンの読み上げ（`aria-label`）も 主人公に合わせて切り替わる
  - 水中（ステージ7）・空中（ステージ8）でも 同じく ガソリン噴射（水中でも 超高圧で 噴射する演出）
  - 検証フック: `__dash.shoot()` / `__dash.setShot(true)` / `__dash.wcPress()` / `__dash.wcRelease()`、`__dash.missiles()` の各要素の `gas` フラグで どちらの攻撃か確認できる

### RIDE（動物・乗り物で高速移動／被弾で消える・2026-11-21）

- **乗り物カプセル**: 各ステージの道中2箇所（1周の約30%・約66%地点。谷・トンネル・ボス闘技場・中ボス／ライバル地点は自動でよけて配置）に、光る `RIDE` カプセルを置く。中に乗り物のミニチュアが入って上下にゆれる
- **種類**: 地上／洞窟（1〜6面）は 🐎**爆走イノシシ**（土煙）と 🏎️**ターボロードスター**（NA風オープン2シーター・排気炎）。7面は 🐬**ジェットイルカ**（泡・ジェット噴射）、8面は 🦅**スカイホーク**（大ワシ・風切り）。主人公は画像を変えずに「乗る」形で描画（車はコックピットに脚をたたみ、動物は わき腹をまたぐ）
- **効果**: 取得で `🐎 RIDE ON!!` / `🏎️ TURBO RIDE!!` などのポップ＋専用SE（`Sfx.rideOn(kind)`）。**移動スピードは約1.62倍**（通常300→486 / ▶加速392→635）。FEVER（392）・スターのターボ（545）とも合算し、**上限640**で頭打ちにして操作不能にならない速さに調整。ボス戦の制限速度中は そちらが優先
- **搭乗中の演出**: 足元・後ろに土煙／排気炎／泡／風切りのパーティクル、乗り物のオーラ。HUD下段に `🐎 RIDE` ピル（スマホ幅ではアイコンのみ）
- **被弾で消える**: 敵・敵弾・トゲなどでダメージを受けると、**乗り物が身代わりになって はじけ飛び**（破片・火花・リング＋`Sfx.rideLose()`＋`RIDE LOST!`）、ハートは減らずに **1.2秒の無敵（点滅）つきで徒歩に戻る**。穴に落ちたときも乗り物は消えてチェックポイントから徒歩で再開。取得直後は0.9秒の無敵つき（取った瞬間に はじけない）。シールド所持中はシールドが先に割れる
- 検証フック: `__dash.rides()` / `__dash.rideInfo()` / `__dash.rideTeleport()` / `__dash.rideTeleportS(kind)` / `__dash.rideNow(kind)` / `__dash.rideLose()` / `__dash.rideHit()` / `__dash.rideDropFall()` / `__dash.rideClearInvuln()` / `__dash.hold(v)` / `__dash.pause(v)`
