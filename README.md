# 紅葉ヒルクライム

嵐山-高雄パークウェイをモチーフにした秋の山道を駆け上がるヒルクライム・ゲーム（1ファイルのHTML）。GitHub Pages で公開中。

- 遊ぶ: https://kokadaroadster-ui.github.io/momiji-hillclimb/
- コース: 嵐山・清滝口ゲート → 花街道 → 小倉山のアップダウン → 保津峡展望台・保津川橋 → 愛宕前のつづら折り → 愛宕橋 → 菖蒲谷池・池の橋・菖蒲ヶ丘展望台 → 紅葉のトンネル → 高雄大駐車場（ロードスターミーティング会場）
- 障害物: 落石・パイロン・バリケード・落ち葉だまり・水たまり（当たると減速）
- Wボタン: 走行中に画面左下のWボタンを押すと、タイヤが鳴ってスピンし、路肩へコースアウト。少し間をおいて立て直し、走行に戻る（キーボードのWはアクセルのまま）
- Wボタン3回連続: 1.6秒以内に3回押すと、3回目でスピンをキャンセルしてバック・トゥ・ザ・フューチャー風のタイムトラベル。チャージ（88 MPH・1.21 GW表示、青白い電撃）→閃光→1985年に切り替わって炎のタイヤ跡を残し爆走→元の時間へ帰還（操作は戻る）。コースも少し先へワープし、タイマーはその間止まる
- Wボタン10回連打: 3.8秒以内に10回押すと、雷と閃光とともに博士（doc.png）が登場し、光るポールの周りでポールダンスを踊る（ディスコ照明・紙吹雪・ファンキーなBGMつき、約5.8秒）。走行は止まらない
- Wボタン長押し: 0.6秒押し続けると、アニメ化したキャラ（giant_char.png）がマリオのキノコのように巨大化してフロントガラス前に出現する（段階的に膨らむ拡大・集中線・スターバースト・キラキラ・軽い画面揺れ・8bitのパワーアップ音、約3秒）。走行は止まらない。短い1回押しのスピンや3回・10回の連打はそのまま
- 天気と時間帯: 夕方から霧・雨を経て夜へ。雨のときはワイパーが動く

## 紅葉ダッシュ！ 〜巨大化＆タイムワープ・アクション〜

同じキャラクター（giant_char.png / doc.png）で作った別ジャンルの横スクロール・ジャンプアクション。嵐山-高雄パークウェイを走り抜けて高雄大駐車場のミーティング会場を目指す。

- 遊ぶ: https://kokadaroadster-ui.github.io/momiji-hillclimb/momiji-dash/
- 操作: ◀▶（←→/A・D）で減速・加速、JUMP（Space/↑）で2段ジャンプ、W でスペシャル。スマホは画面下のボタン
- W: ゲージ満タンで巨大化（無敵・障害物を体当たりで粉砕、集中線・スターバースト・8bitパワーアップ音）、⚡1.21GWバッテリー所持中なら 88MPH タイムワープ加速。もう一度パワーアップすると超巨大化（MEGA）
- ステージ: 清滝口の紅葉 → 保津川橋 → 観空台の観覧車とトンネル → 深い森 → 紅葉のトンネル・谷 → 高雄大駐車場（色とりどりのNAロードスターがリトラを開閉）
- ドクはボーナス地点2か所とゴールのステージでミラーボール＆ディスコライト付きのポールダンス応援（4つ打ちビート、「GREAT SCOTT!!」テロップ、回復＋バッテリー）
- ステージ選択: タイトル画面で「ステージ1：嵐山-高雄（紅葉コース）」と「ステージ2：恐怖の地下ダンジョン」を選べる。ステージ1のゴール画面／THE END 画面からもステージ2へ進める

### ステージ2：恐怖の地下ダンジョン

- 背景: 暗い石造りの地下迷宮（レンガの壁・アーチと柱・揺らめく松明の光の輪・鍾乳石と鎖・紫〜深紅の霧・骨の転がる石畳・落とし穴）
- 道中の敵: コウモリ（踏める）／スケルトン／転がる岩／トゲ罠（踏めない）
- BGM: 低いオルガンとトライトーン、心音のような低音の不気味な曲（`track: 'dungeon'`）。ボス戦では刻む低音と金管スタブで緊迫を煽る曲（`track: 'dungeon_boss'`）に切り替わる。🔊/🔇・Mキーのミュートに連動
- ボス: 「非案内人（STAFFではありません）」（dungeon_boss.png）。Tシャツの文言どおり「案内拒否ショックウェーブ」「説明不能ダークボール」「案内板投擲」で攻めてくる。低く降りた瞬間の踏みつけ、落ちた案内板を投げ返す反撃、巨大化・ワープ・ターボの体当たりで撃破
- 撃破すると最深部の扉（出口）が開き、既存のドラクエ風エンディング（ダンジョン用のメッセージ・スタッフロール）へ

### 追加の敵キャラ・アイテム（2026-11-20）

- 紅葉タカ（ステージ1）: 上空を旋回し、近づくと急降下してくる。踏みつけ可能。急降下中は「!」が出る
- 紅葉シカ（ステージ1）: 左右にステップしながら道をふさぐ。枝角があるので踏めない（ジャンプでよける）。角に紅葉がついている
- 鬼火（ステージ2）: 青白い炎がゆらゆら浮遊。踏めず、触るとダメージ。高度が低いときはジャンプで越える
- 呪いのランタン（ステージ2）: 天井から鎖で吊られ、左右に振り子のように揺れる。振り切れたすき間を抜ける
- 新アイテム: POWERオーブ（取ると即パワーアップ／2回目で超巨大化）、シールド（12秒間、1回分のダメージを防ぐ青いバリア）、×2スコアブースト（11秒間、スコアとコインが2倍）。HUDの下段に効果時間、プレイヤー付近にタイマーを表示

### 2段階パワーアップ（BIG → MEGA）

- 1回目のパワーアップ（Wゲージ満タン、またはPOWERオーブ）で「BIG」（1.55倍・約7.6秒）
- BIGの状態でもう一度パワーアップすると「MEGA」（2.15倍・約10.6秒）。専用の紫〜紅のオーラ・地面の二重リング・周回する光・MEGA!!表示・専用8bitパワーアップ音つき
- MEGAは着地で画面が大きく揺れ、足元の敵（半径170）をふき飛ばす。当たり判定も2段階で拡大。ゲージは巨大化中もたまる（2回目のパワーアップを狙える）

### ボスの可変攻撃（本気モード）

- 残りHP 65%以下で「本気」、35%以下で「本気MAX」にフェーズ変化（HPバーが赤く脈打ち、⚠ SPEED UP / SPEED MAX バナー表示）
- フェーズごとに移動速度・攻撃間隔・弾速が上がる（速度×1.42 / ×1.84、BGMのテンポも上昇）
- 本気からはドクが3方向の扇状弾、非案内人が3方向のダークボール／両方向ショックウェーブを使う。本気MAXではドクの突進（ジャンプでよける）と連射、超加速バースト（残像スピード線）、非案内人のフェイントジャンプ→両方向衝撃波が加わる
